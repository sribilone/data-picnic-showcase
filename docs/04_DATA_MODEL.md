# โครงสร้างข้อมูลและฟังก์ชัน

ไฟล์จริงอยู่ที่ `supabase/migrations`

## ตาราง

| ตาราง | เก็บอะไร | ใครอ่านตรงได้ | อ้างอิง |
|---|---|---|---|
| `admins` | อีเมลผู้ดูแล | ผู้ดูแล | BR-016 |
| `rounds` | รอบ สวิตช์รับผลงาน สถานะโหวต การแสดงบนบอร์ด กติกาต่อรอบ | ทุกคน | FR-032 ถึง FR-040 |
| `works` | ผลงาน ชื่อและอีเมลเจ้าของ ณ ตอนส่ง ภาพ สัดส่วน สถานะ | เจ้าของ และผู้ดูแล | FR-022 ถึง FR-031 |
| `votes` | หัวใจ เก็บ `voter_key` ที่เข้ารหัสทางเดียว ไม่เก็บ user id | ไม่มีใคร | BR-003 BR-007 |
| `audit_log` | การกระทำของผู้ดูแล | ผู้ดูแล | FR-054 FR-055 |
| `private.settings` | ค่าลับสำหรับเข้ารหัส voter_key | ไม่มีใคร | BR-007 |

### สถานะของรอบ

| คอลัมน์ | ค่า |
|---|---|
| `upload_open` | true เปิดรับผลงาน · false ปิด |
| `vote_status` | `not_started` ยังไม่เปิด · `open` เปิดโหวต · `closed` ปิดโหวตแล้ว |
| `is_shown` | แสดงบนบอร์ดได้ครั้งละ 1 รอบ บังคับด้วย unique index |
| `show_counts` | `after_close` ค่าเริ่มต้น · `always` · `never` |

### voter_key

`voter_key = HMAC_SHA256(user id, ค่าลับใน private.settings)`
ระบบรู้ว่าคนเดิมกดซ้ำหรือใช้หัวใจครบแล้ว แต่ย้อนกลับเป็นตัวตนไม่ได้ถ้าไม่มีค่าลับ ซึ่งไม่มีใครอ่านได้ผ่าน API

## ที่เก็บไฟล์

| เรื่อง | ค่า |
|---|---|
| bucket | `works` อ่านได้สาธารณะ |
| ที่อยู่ไฟล์ | `{round_id}/{user_id}/{เวลา}.jpg` |
| ชนิดไฟล์ | PNG JPG ไม่เกิน 10 MB · หน้าเว็บย่อเหลือด้านยาวไม่เกิน 2,000 พิกเซลก่อนอัปโหลด |
| เขียนได้ | เฉพาะโฟลเดอร์ `user_id` ของตัวเอง |
| ลบได้ | เจ้าของ และผู้ดูแล |

ฟังก์ชันที่ลบผลงานคืนที่อยู่ไฟล์ให้หน้าเว็บลบออกจาก Storage ผ่าน API เพราะ Supabase ไม่แนะนำให้ลบไฟล์ด้วย SQL

## ลบบัญชีผู้เรียนหลังจบกิจกรรม

ทำใน Server Action ด้วย `createServiceClient()` ใน `src/lib/supabase/server.ts`
ตรวจ `admin_can_purge()` ก่อน แล้วลบผู้ใช้ทุกคนที่อีเมลไม่อยู่ในตาราง `admins`
ผลงานยังเก็บชื่อและอีเมลเจ้าของไว้ เพราะเก็บไว้ ณ ตอนส่ง
