# เอกสารความต้องการระบบ Showcase โหวตผลงาน Infographic

รุ่น 0.4 · 8 ตุลาคม 2569

---

## 1. เอกสารนี้คืออะไร

เอกสารนี้กำหนดความสามารถของระบบ Showcase สำหรับคลาส AI for HR
ผู้เรียนส่งผลงาน Infographic ขึ้นบอร์ด เพื่อนในคลาสเข้าสู่ระบบด้วยบัญชี Google แล้วโหวตผลงานที่ชอบ
ผู้สอนกำหนดรอบ เปิดปิดการรับผลงานและการโหวต และส่งออกผลโหวตพร้อมชื่อเจ้าของผลงาน

**ปัญหาหลักที่ต้องแก้**

| # | ปัญหา |
|---|---|
| 1 | ผู้เรียนต้องเห็นผลงานของเพื่อนทั้งคลาสในที่เดียว โดยไม่รู้ว่าเป็นของใคร |
| 2 | การโหวตต้องยืนยันตัวตนเพื่อกันโหวตซ้ำ แต่ห้ามเปิดเผยว่าใครโหวตผลงานใด |
| 3 | วันเดียวมีสองรอบ รอบบ่ายต้องเริ่มบอร์ดว่างโดยไม่เห็นผลงานรอบเช้า |
| 4 | ผู้สอนต้องได้ผลโหวตพร้อมชื่อเจ้าของผลงานไปใช้ต่อ |

## 2. พื้นฐานของระบบ

### 2.1 Role

| Role | คือใคร | เข้าสู่ระบบ |
|---|---|---|
| ผู้เยี่ยมชม | ทุกคนที่เปิดลิงก์บอร์ด | ไม่ต้อง |
| ผู้เรียน | ผู้เยี่ยมชมที่เข้าสู่ระบบด้วยบัญชี Google แล้ว | ต้อง |
| ผู้ดูแล | ผู้สอน อีเมลอยู่ในรายชื่อผู้ดูแล | ต้อง |

ผู้ดูแลทำทุกอย่างที่ผู้เรียนทำได้ด้วย

### 2.2 Object

| Object | สร้างเมื่อ | จบชีวิตเมื่อ |
|---|---|---|
| รอบ | ผู้ดูแลเพิ่มรอบ | ผู้ดูแลลบรอบ |
| ผลงาน | ผู้เรียนส่งผลงาน | เจ้าของยกเลิกการส่ง หรือผู้ดูแลลบ |
| หัวใจ | ผู้เรียนโหวตผลงาน | ผู้เรียนถอนโหวต ผลงานถูกถอน ซ่อน หรือลบ |
| บัญชีผู้เรียน | เข้าสู่ระบบครั้งแรก | ผู้ดูแลลบบัญชีผู้เรียนทั้งหมด |
| ผู้ดูแล | ผู้ดูแลเพิ่มอีเมล | ผู้ดูแลลบอีเมล |

### 2.3 เทคโนโลยีที่ตกลงแล้ว

| ส่วน | ใช้ |
|---|---|
| หน้าเว็บ | Next.js บน Vercel ดึงโค้ดจาก GitHub |
| ฐานข้อมูล การเข้าสู่ระบบ ที่เก็บไฟล์ | Supabase |
| การเข้าสู่ระบบ | Google OAuth |
