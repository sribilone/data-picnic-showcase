# AI for HR Showcase

บอร์ดผลงาน Infographic สำหรับคลาส AI for HR · data.picnic
ผู้เรียนส่งผลงาน เพื่อนเข้าสู่ระบบด้วย Google แล้วโหวต ผู้สอนกำหนดรอบและส่งออกผลโหวต

## เทคโนโลยี

Next.js 15 · Tailwind CSS 4 · Supabase Auth Postgres Storage · Vercel

## เริ่มต้น

1. ตั้งค่าบริการตาม `docs/03_SETUP.md`
2. รันบนเครื่อง

```bash
npm install
cp .env.example .env.local
npm run dev
npm test
```
