## 4. ระยะงาน

เวลาเป็นค่าประมาณ นับเป็นวันทำงาน

| ระยะ | งาน | FR หลัก | เสร็จเมื่อ | เวลา | สถานะ |
|---|---|---|---|---|---|
| P0 | ตั้งค่า GitHub Supabase Google Vercel ตาม `03_SETUP.md` | | เปิดเว็บบน Vercel แล้วเข้าสู่ระบบด้วย Google ได้ | 0.5 | รออาจารย์ |
| P1 | ฐานข้อมูล ตาราง RLS ฟังก์ชัน Storage | ทุกกลุ่ม | รัน migration บน Supabase ผ่าน และ `supabase/tests` ผ่านทุกข้อ | 0.5 | ร่างเสร็จ ทดสอบในเครื่องผ่าน |
| P2 | พื้นฐานหน้าเว็บ ธีม เข้าสู่ระบบ middleware ตรวจสิทธิ์หลังบ้าน | F1 | เข้าสู่ระบบ ออกจากระบบ และบัญชีที่ไม่ใช่ผู้ดูแลเจอ SCR-046 | 0.5 | โครงเสร็จ build ผ่าน |
| P3 | ฝั่งผู้เรียน บอร์ด โหวต ผลงานแบบขยาย ส่งผลงาน ผลงานของฉัน | F2 F3 F4 | ทำครบทุกแถวของ `05_TEST_CHECKLIST.md` หมวดผู้เรียน | 2 | ยังไม่เริ่ม |
| P4 | หลังบ้าน รอบ ผลงาน ผลโหวต ส่งออก ตั้งค่า ลบข้อมูล | F5 F6 F7 F8 | ทำครบทุกแถวหมวดผู้ดูแล | 1.5 | ยังไม่เริ่ม |
| P5 | ทดสอบ โหลด 60 คน เบราว์เซอร์ 3 ตัว จอ 375 ถึง 1440 ความเป็นส่วนตัว | NFR | p95 การโหวตไม่เกิน 1 วินาที และไม่มีชื่อเจ้าของหลุดไปฝั่งผู้เรียน | 1 | ยังไม่เริ่ม |
| P6 | ซ้อมจริง 1 รอบกับบัญชีทดสอบ และเตรียมวันสอน | | ผ่านรายการตรวจก่อนวันสอน | 0.5 | ยังไม่เริ่ม |

รวมประมาณ 6.5 วันทำงาน ควรเสร็จ P5 ก่อนวันสอนอย่างน้อย 3 วัน เผื่อแก้ไข

### ลำดับงานใน P3

1. บอร์ดอ่านอย่างเดียว ใช้ `shown_round()` `board()` และ `ArtFrame`
2. สถานะบอร์ดว่าง SCR-005 และไม่มีรอบที่แสดง SCR-006
3. โหวตและถอนโหวต พร้อมตัวนับหัวใจ ใช้ `cast_vote()` `retract_vote()` `my_votes()`
4. ผลงานแบบขยาย 3 แบบตามสัดส่วนภาพ
5. ส่งผลงาน ย่อภาพ อัปโหลด แล้วเรียก `submit_work()`
6. ผลงานของฉัน แก้ไข ยกเลิกการส่ง และผลหลังปิดโหวต
7. ผลโหวตบนบอร์ด SCR-007

### ลำดับงานใน P4

1. จัดการรอบ และกล่องเพิ่มหรือแก้ไขรอบ
2. จัดการผลงาน ซ่อน นำกลับ ลบ
3. ผลโหวตและส่งออก CSV
4. ตั้งค่า ผู้ดูแล ลบข้อมูลหลังจบกิจกรรม ประวัติ

## 5. Git และการ deploy

| เรื่อง | วิธี |
|---|---|
| branch หลัก | `main` deploy ขึ้น Vercel อัตโนมัติ |
| งานแต่ละชิ้น | แตก branch เช่น `p3-board` แล้วเปิด Pull Request · Vercel สร้างลิงก์ Preview ให้ทดสอบ |
| ข้อความ commit | ขึ้นต้นด้วยระยะงานและรหัส SCR เช่น `P3 SCR-003 โหวตและถอนโหวต` |
| ฐานข้อมูล | แก้โครงสร้างด้วยไฟล์ใหม่ใน `supabase/migrations` เท่านั้น ห้ามแก้ไฟล์ที่รันไปแล้ว |
| ความลับ | `.env.local` ไม่ขึ้น Git · ค่าจริงอยู่ใน Vercel และ Supabase |

## 6. ความเสี่ยงและวิธีรับมือ

| ความเสี่ยง | ผลกระทบ | วิธีรับมือ |
